# نظام اليوسف — تطبيق سطح مكتب (Tauri)

هذا المشروع بيغلّف نفس ملف الـ ERP (`dist/index.html`) في تطبيق ديسكتوب حقيقي
باستخدام **Tauri**، مع تخزين البيانات في ملف JSON فعلي على القرص بدل
`localStorage` في المتصفح.

## إيه اللي اتغيّر في الكود عن النسخة المنظّفة؟
تغييرات محدودة جدًا ومركّزة بس على التخزين (٤٦ سطر بس اتغيّروا، والباقي زي ما هو):
1. الروابط اللي كانت بتجيب Chart.js و xlsx من الإنترنت (CDN) بقت بتجيبهم من
   ملفات محلية جوه `dist/vendor/` — يعني التطبيق يشتغل بالكامل من غير إنترنت.
2. دالتَي `save()` و `load()`: لو التطبيق شغّال جوه Tauri، بيقروا/يكتبوا ملف
   `data.json` حقيقي على القرص (عن طريق أمرين في كود Rust: `save_data` و
   `load_data`). لو نفس الملف اتفتح في متصفح عادي (من غير Tauri)، بيرجع
   يشتغل بنفس طريقة `localStorage` القديمة بالظبط — يعني تقدر تفتحه في
   المتصفح للمقارنة والتجربة زي الأول.

## ⚠️ حاجة مهمة لازم تعرفها
البيئة اللي بنيت فيها المشروع ده معندهاش صلاحية توصل لموقع Rust الرسمي
(rustup.rs) عشان تثبت نسخة حديثة من Rust — واللي متاح فيها بس نسخة قديمة
(1.75) من مستودعات Ubuntu، ومكتبات Tauri الحديثة محتاجة نسخة أحدث. يعني
**لسه ما قدرتش أعمل build كامل واختبره فعليًا بعيني في نفس البيئة دي.**

الحل: خليت GitHub Actions (ملف `.github/workflows/build-windows.yml`) هو
اللي بيعمل الـ build — لأن أجهزة GitHub عندها Rust حديث دايمًا، ومفيش أي
قيود شبكة. ده كمان هو نفس الأسلوب المعتاد لبناء تطبيقات ويندوز أصلاً (مش
بيتعمل build لويندوز من لينكس عادةً، بيتعمل على ويندوز نفسه أو على CI).

**يعني: لسه محتاج نتأكد إن أول build فعلي هيعدي كويس من غير أخطاء —
الكود اتكتب بعناية وبناءً على بنية Tauri v2 الرسمية، لكن أول تجربة حقيقية
هتكون على GitHub.** لو حصل أي خطأ في الـ build، ابعتلي رسالة الخطأ من
صفحة Actions وهعالجها فورًا.

## طريقة الحصول على ملف تثبيت Windows (الأسهل - من غير أي تثبيت عندك)

1. اعمل حساب على [github.com](https://github.com) لو معندكش (مجاني).
2. اعمل مستودع (repository) جديد، خليه **Private** لو البيانات حساسة.
3. ارفع كل ملفات المجلد ده (`yousef-erp-app`) للمستودع — أسهل طريقة:
   من موقع GitHub نفسه، "Add file" → "Upload files"، واسحب كل حاجة.
4. روح لتبويب **Actions** في المستودع — هتلاقي "Build Windows Installer"
   شغّال أوتوماتيك (لأنه بيشتغل مع كل رفع). لو مشتغلش لوحده، دوس
   "Run workflow".
5. لما يخلص (يدّي حوالي 10-15 دقيقة أول مرة)، هتلاقي تحت اسم الـ run
   قسم **Artifacts** فيه ملف `yousef-erp-windows-installer` — نزّله،
   فكّه، وهتلاقي جواه ملف `.msi` أو `.exe` — ده ملف التثبيت بتاعك.
6. شغّل ملف التثبيت على أي جهاز ويندوز، وهيتثبت زي أي برنامج عادي.

## مكان حفظ البيانات على الجهاز
بعد التثبيت، البيانات بتتحفظ في:
`%APPDATA%\com.alyousef.erp\data.json`
لسه ينفع تعمل نسخة احتياطية بنفس زرار "تصدير نسخة احتياطية (JSON)"
الموجود جوه البرنامج — بيشتغل بنفس الطريقة القديمة تمامًا.

## الأيقونة
الأيقونة الحالية (`src-tauri/icons/`) بسيطة مؤقتة بألوان البرنامج (كحلي +
كهرماني) على شكل مبنى — لو عندك لوجو حقيقي للشركة، استبدل ملفات PNG/ICO
دي بنفس الأسماء ونفس المقاسات.

## لو حابب تبني محليًا على جهاز Windows عندك (اختياري، مش لازم)
لو عندك جهاز Windows فعلي وحابب تبني بنفسك من غير GitHub:
1. ثبّت [Rust](https://www.rust-lang.org/tools/install) و
   [Node.js](https://nodejs.org) (لو مش مثبّتين).
2. من داخل مجلد المشروع: `cargo install tauri-cli --version "^2.0.0"`
3. بعدها: `cargo tauri build`
4. الملف الناتج هيبقى في:
   `src-tauri/target/release/bundle/msi/` أو `.../bundle/nsis/`
